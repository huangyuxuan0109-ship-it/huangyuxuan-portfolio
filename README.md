# 黄虞萱作品集

个人视觉设计作品网站，包含地产、教育、文具、游戏、PPT、画册、包装、物料及其他设计项目。

## 网站入口

- 首页：`index.html`
- 作品目录：`portfolio.html`
- 关于我：`about.html`

## 项目结构

- `public/`：首页与通用图片素材
- `portfolio-assets/`：作品目录素材
- `project-*-assets/`：各项目页面的图片、视频、字体及 PDF 素材
- `styles.css`：网站通用样式
- `*-pop.css`：波普几何主题样式

## 使用方式

这是一个纯静态网站，不需要构建工具。直接打开 `index.html` 即可浏览，也可以从仓库根目录部署到 GitHub Pages。

## 设计说明

网站整体使用波普与几何视觉语言，并针对桌面端和移动端进行了响应式适配。所有页面素材均使用仓库内相对路径，方便在线部署。
